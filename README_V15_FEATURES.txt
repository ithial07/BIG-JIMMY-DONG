ArdaBest MUD Client v15 - Static Background Picker

Added in v15:
- Background... button on the Terminal page.
- Opens a file picker GUI for PNG, JPG, JPEG, BMP, and WEBP files.
- Stretches the selected image behind the terminal text, like a Mudlet static main-console background.
- Clear background button.
- Local commands: /set background and /clear background.
- Selected background path is saved in profile.json and restored on next launch.

Kept from v14:
- Full MUD room number in YOU ARE HERE label.
- Square/circle mapper shape.
- Highlight, line, and pulse color dropdowns.
- Built-in HP/Mana/Move/XP bars with checkboxes.
- Generated custom art emoji/icon dropdown database.
- RotS Automapper trigger by default.
- rotsmud.org port 3791 default.
