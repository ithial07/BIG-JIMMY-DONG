ArdaBest MUD Client v17 - Background Picker + Full MUD Room ID Fix

Fixed in v17:
- Background button is now actually wired to a GUI file picker.
- File picker supports .png, .jpg, .jpeg, .bmp, and .webp.
- Terminal no longer turns white when no background is set.
- Background images are stretched behind the terminal and darkened so text stays readable.
- Clear background returns the terminal to a black readable console.
- Current room label now prefers the full MUD room number from the MUD line, such as #32647.
- The status/details line now shows both MUD room number and mapper room id when possible.

Run START-HERE-WINDOWS.bat to build.
