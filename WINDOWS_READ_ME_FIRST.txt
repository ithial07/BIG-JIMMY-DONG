ARDABEST CLIENT v7

1. Unzip this whole folder.
2. Double-click START-HERE-WINDOWS.bat.
3. Let it install/build if needed.
4. Open package-windows.
5. Double-click RUN-ARDABEST-CLIENT.bat.

The Triggers tab now has a Mudlet-style editor.
The default RotS Automapper trigger is included by default.
It detects:

Dark Tunnel Passage (#31902) [ Floor ] Exits are: E S W

It uses #31902 as the real MUD room number and centers the ARDABEST map.
