ArdaBest Client v14

Changes:
- YOU ARE HERE now shows the printed MUD room number when available, not just the internal mapper id.
- Added mapper color controls above the map: Highlight, Lines, and Pulse.
- Color choices include Bright Green, Bright Blue, Bright Red, Bright Yellow, Bright Pink, Bright Purple, Green, Light Blue, Orange, and White.
- Added built-in bottom status bars: Health, Mana, Movement, and XP. Each has a checkbox and collapses when unchecked.
- Bars parse prompts like: [HP: 166/170 S: 55/55 MV: 127/127]
- Added generated fantasy/MUD art icons to the emoji/icon dropdown: orc, goblin, troll/ogre, butcher, armor, blacksmith, general store, gate, trophy, skeleton, bandit, tavern, alchemy, dwarf, elf, wolf, skull.
- Existing Start Mapping / Stop Mapping, square/circle room shape, save map, scripts, aliases, triggers remain included.
